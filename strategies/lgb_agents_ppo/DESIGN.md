# 四层选股系统设计

```
                  data/clean/  唯一真相源
                       │
        ┌──────────────▼──────────────────────────────┐
        │  1 初筛层   LightGBM + Qlib                 │
        │    全量因子打分 → Top-N 候选池（约 100 只）  │
        └──────────────┬──────────────────────────────┘
                       │
        ┌──────────────▼──────────────────────────────┐
        │  2 精研层   TradingAgents                   │
        │    研报/新闻逻辑验真 → 排除风险标的          │
        │    ⚠ 无法历史回测，见「前视问题」            │
        └──────────────┬──────────────────────────────┘
                       │
        ┌──────────────▼──────────────────────────────┐
        │  3 执行层   PPO                             │
        │    动态仓位水平 [0,1]                        │
        └──────────────┬──────────────────────────────┘
                       │
        ┌──────────────▼──────────────────────────────┐
        │  4 风控层   低过拟合设计（贯穿 1、3 层）     │
        │    + 既有硬约束（回撤三档、下单前置）        │
        └─────────────────────────────────────────────┘
```

标的范围：中证 1000（约 1800 只）。

---

## 第 4 层不是运行时的一层

「DoubleEnsemble 风格的低过拟合设计做安全垫」—— 它不是串在数据流里的一个环节，
而是**贯穿第 1、3 层的训练方法**。这个定位很重要：过拟合造成的亏损，
事后任何风控规则都拦不住，因为账面上它看起来一直是「策略正常运行」。

### 借鉴 DoubleEnsemble 的两个机制

**样本重加权（SR, Sample Reweighting）**

按每个样本在训练过程中的 loss 曲线给权重：模型已经拟合得很好的样本降权，
一直学不会的样本升权。原论文的动机是「让模型别在容易的样本上反复用功」。

用在这里的价值是另一层：A 股的收益分布极不均衡，大部分样本是噪声。
不加权时模型会被大量「涨跌都在 ±1% 以内」的样本主导，
学到的是均值回复的噪声结构。

**特征筛选（FS, Feature Selection）**

把某个特征列打乱，看模型表现掉多少 —— 掉得少说明这个特征没在贡献，剔除。
Alpha158 有 158 个因子，其中大部分互相高度相关。

对本项目尤其重要：8 种子实验已经证明同架构模型高度相关
（方差比理论值差 2.1 倍）。特征筛选能造出**真正有差异的子模型**，
让集成不再是「八个几乎相同的模型取平均」。

### 加上本项目自己踩出来的约束

| 机制 | 由来 |
|------|------|
| 多种子必测 | 8 种子 Sharpe 区间 -0.491 ~ +0.532，中位数 -0.027 |
| 参数看邻域 | 50只/20日 Sharpe +0.650，邻居 -1.080，孤立尖刺 |
| 分段检验 | 全期冠军在两个子段都为负 |
| 因子按可获得时点滞后 | margin_bal_chg 滞后 1 日即失去显著性 |
| 数据完整度门槛 | 两融因子仅 115/1108 期有数据 |
| Newey-West 修正 | 重叠窗口未修正 t=-24.44，修正后 -7.22 |

**这套检验是准入条件，不是事后报告。** 任何模型进入下一层之前必须先过。

## 第 1 层：初筛

### 为什么用 LightGBM 而非继续 ALSTM

| | ALSTM | LightGBM |
|---|---|---|
| 训练耗时 | 10 分钟/次（GPU） | 约 1 分钟（CPU） |
| 参数量 | 52,609 | 树结构，可解释 |
| 特征重要性 | 无 | 原生支持，是 FS 的基础 |
| 8 种子 Sharpe 中位数 | -0.027 | 待测 |

关键是**特征重要性**：没有它就做不了 DoubleEnsemble 的特征筛选。
另外训练快 10 倍，多种子实验从 90 分钟压到 10 分钟以内，
使得「每次改动都跑完整检验」成为可能。

### 输入

- Alpha158（158 个量价因子，Qlib 内置）
- `dragon_count_20`（龙虎榜 20 日累计，已验证 IC -0.0627 / t -7.22，滞后 1 日）

`margin_*` 与 `north_net_pct` 因数据缺失被剔除，补齐数据后再纳入。

### 输出

`candidates.parquet` —— 每个调仓日的 Top-N 候选池（N 约 100，
远大于最终持仓 30~50，给第 2 层留出剔除空间）。

## 第 2 层：精研

### 前视问题必须先讲清楚

**LLM 读研报做历史回测有无法修正的前视偏差。**

模型权重里已经包含 2022~2024 年发生过什么。让它「阅读」一篇 2022 年的研报
并判断风险，它实际是在用已知结果反推。这不是滞后一天能解决的 ——
未来信息在权重里，不在输入里。

后果：回测会显示极好的结果，实盘完全复现不了。比之前踩过的任何坑都隐蔽。

### 两条可行路径

**A. 只用于实盘，不进回测**（推荐先做这个）

承认这一层无法被历史验证，定位为「人工复核的自动化」。
第 1、3 层照常回测，第 2 层的效果通过实盘前瞻式记录来评估。

**B. 前瞻式验证**

从启用之日起记录每次判断与后续表现，积累 6 个月以上再评估。
慢，但结论可信。

### 数据源缺口

研报与新闻数据当前完全没有。可选：

| 来源 | 覆盖 | 门槛 |
|------|------|------|
| Tushare 新闻快讯 | 较全 | 需较高积分 |
| 巨潮公告 | 公告全量 | 需自建爬虫 |
| 东财研报 | 研报摘要 | 需自建爬虫 |

**这一层建议放到最后做** —— 前视问题决定了它无法用回测证明价值，
而第 1、3、4 层能用现成方法验证。先把能验证的做扎实。

## 第 3 层：执行

沿用现有 `train_ppo.py`。已验证的效果：

| 配置 | 总收益 | 最大回撤 | Sharpe |
|---|---|---|---|
| 集成分数满仓 | +56.62% | 17.06% | 0.650 |
| 集成分数 + PPO | +39.64% | **13.96%** | **0.899** |

PPO 做的是**拿收益换风险控制**，平均仓位 30%。

### 待补

- **PPO 自身的多种子实验**（当前 0.899 可信度未知）
- 组合状态在推理时曾恒为零，已修复；需重新验证修复后的实盘表现

---

## 实施顺序

按「能被验证」排序：

1. **第 1 层 + 第 4 层** —— 两者耦合（FS 依赖特征重要性），一起做
2. **第 3 层多种子验证** —— 补上 PPO 的可信度评估
3. **三层联合回测 + 全套检验** —— 多种子、参数邻域、分段
4. **第 2 层** —— 数据源与前视问题都解决后再做

第 1 步产出的是候选池与一套可复现的检验报告；
若第 4 层的低过拟合设计有效，应表现为：多种子 Sharpe 分布收窄、
参数网格从孤立尖刺变成连片区域、分段检验符号一致。

**这三条就是验收标准。** 达不到就说明这条路和 ALSTM 一样走不通，
应及早止损而非继续调参。
